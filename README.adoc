= OpenShift BizOps Operations Workshop

Four one-hour progressive sessions that teach OpenShift day-2 BizOps skills on a single empty cluster: architecture and access, images/logs/scale/HA, deploy strategies and configuration, and troubleshooting with capacity awareness.

== View the Course

The full course is published at: https://example.github.io/openshift-bizops-workshop

NOTE: Replace `example` with your GitHub org or user before publishing.

== Local Development

Use Node.js 18 (see `.nvmrc`). Antora 2.x does not run reliably on newer Node major versions.

[source,bash]
----
nvm use
npm install
npm run dev
----

This starts a live-reload server at http://localhost:3000.

== Build the Site

[source,bash]
----
npx antora generate site.yml
----

The generated site is output to `gh-pages/`.

== Repository Structure

[cols="2,4",options="header"]
|===
| Directory | Purpose
