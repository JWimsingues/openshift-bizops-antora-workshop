== Day-2 operations on a single OpenShift cluster

Four one-hour hands-on sessions for BizOps engineers. You start from an empty OpenShift cluster, deploy a sample application, then practice traffic flow, day-2 operations, safe configuration changes, troubleshooting, and capacity awareness.
